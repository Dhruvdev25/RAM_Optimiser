# Changelog

## 1.0.0 — initial release candidate

- Added a dark PySide6 dashboard with vector CPU, GPU, memory, and storage gauges.
- Added background system polling, optional NVIDIA NVML metrics, local history, and settings.
- Added conservative working-set Boost modes, process identity checks, process inspection, graceful close, and separately confirmed force termination.
- Added optional Auto Boost, game-session tracking, reversible standard Run-key startup entries, and system tray controls.
- Prepared a one-file Windows executable and a per-user Inno Setup installer configuration.
- The application and installer are unsigned. See `TESTING.md` for verified checks and remaining Windows release validation.
